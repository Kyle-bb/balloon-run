# Balloon Defense 2.0

A thrilling tower defense game built with Phaser.js, React, and TypeScript. Defend your base against waves of balloons with upgraded weapons, special enemies, and power-ups!

## Features

### 🎈 Enemy Types
- **Regular Balloons**: Standard layered balloons (1-3 layers)
- **Boss Balloons**: Massive 5-layer balloons with crowns
- **Fast Balloons**: Quick-moving orange balloons
- **Armored Balloons**: Tough purple balloons
- **Explosive Balloons**: Dangerous pink balloons

### ⚡ Power-ups
- **Health**: Restore 30 HP
- **Damage**: +1 projectile damage
- **Speed**: +50 projectile speed
- **Multishot**: +1 projectile per shot

### 🔊 Audio & Visual Effects
- Procedural sound effects for all actions
- Particle explosions and muzzle flashes
- Dynamic visual feedback

### 🎮 Gameplay
- Horizontal movement with A/D or arrow keys
- Auto-firing turret system
- Upgrade system between stages
- Increasing difficulty with new enemy types

## Controls

- **A/D or Left/Right Arrow**: Move turret
- **Touch Controls**: Mobile-friendly directional buttons

## Development

```bash
npm install
npm run dev
npm run build
```

## Tech Stack

- **Phaser.js**: Game engine
- **React**: UI framework
- **TypeScript**: Type safety
- **Vite**: Build tool
- **Web Audio API**: Sound effects
